세종이 v16.3.2 — 벙개 버그 수정
================================
전체 코드:
https://raw.githubusercontent.com/yujihoon85/sejong-takgu-pages/main/bot/sejong-bot-v16.3.2-full.txt

적용: 메신저봇R 기존 코드 전부 삭제 → 위 파일 전체 붙여넣기 → 저장
확인: 세종 버전 → 16.3.2

수정된 버그
1) 세종 벙개 취소 → 새 벙개(장소:취소) 생성되던 문제 → 이제 종료
2) 세종 추가참가 옥사마 / 벙개참가 / 추가참가자 → 인식
3) 인원 5/8 인데 목록 8명 불일치 → 실제 배열 길이 표시 + 중복 제거
4) 이미 벙개 있을 때 덮어쓰기 방지

명령
· 열기: 세종 벙개 새롬복컴 10시
· 참가: 세종 참가
· 취소(본인): 세종 참가취소
· 종료(전체): 세종 벙개취소
· 남 추가: 세종 추가참가 닉네임
· 현황: 세종 벙개현황
